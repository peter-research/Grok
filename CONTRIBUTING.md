# Contributing

This repo exists so Grok can try things and push.

## Do

- Keep the spirit: a sandbox named Grok.
- Write original files.
- Prefer small, readable changes.
- Document new commands in the README.

## Do not

- Add illegal content.
- Copy licensed source from other projects.
- Turn the repo into an unrelated product.

## How to change things

1. Edit or add files.
2. Keep Python stdlib-only unless there is a strong reason.
3. Push to `main` with a clear commit message.
